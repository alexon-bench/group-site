Hamming — Domain Redesign QC Tool

Checks redesigned domain sequences against the agreed template. Flags missing residues, residues outside the domain, and unexpected mutation counts before you order inserts.

1Template domain sequence

A design PASSES only if its length exactly matches the template and its substitution count falls within this range. Any length mismatch always FAILS — it means residues are missing or extra.
