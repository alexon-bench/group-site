Mass ↔ Molarity

Convert between DNA mass and molar concentration using the fragment length, an average weight per base pair, and a volume.

bp
g/mol/bp

650 g/mol/bp is the common average for double-stranded DNA; use 660 or your own value if you prefer.

This tool does not use any browser storage. All values live only in this page and are cleared when you reload or close the tab.
