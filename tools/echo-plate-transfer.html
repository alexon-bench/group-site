Echo Planner and Worklist Generator

Create a sample "group" for each reagent, click or drag to assign it source wells and destination wells, then set its transfer volume in the panel next to its source plate. Add more than one source plate if you need to — each gets its own name, its own groups, and its own exported CSV, all paired with the single destination plate. A group belongs to exactly one source plate; only the plate whose group is currently being edited is clickable. A destination well can belong to several groups at once. Group and plate labels are for your reference only and are never written to the CSV.

Before running this on the Echo: reopen each exported CSV and confirm the source/destination wells and volumes match what you intended, and double-check the file name and file type are what the Echo software expects for import. Always run the transfer in the instrument software's simulation/preview mode before executing it for real.

This tool does not use any browser storage. Group and source-plate labels are for your reference only and are not written to the CSV. Everything you build lives only in this page and is lost when you reload or close the tab, so export the CSV before navigating away.
