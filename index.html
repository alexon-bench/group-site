Contribute safely

You do not need to know Git.

Start with an idea and use any AI assistant or code editor you trust. The default contribution path changes only one standalone file, so the shared site stays protected. Every published tool is checked for a landing-page card and the standard MTech navigation.

  1. 1
    Give your builder the MTech brief

    Paste the provider-neutral guide into Claude, ChatGPT, Codex, or another assistant before describing your tool.

  2. 2
    Create one HTML file

    The tool carries its own layout, styling, and behavior. It does not install packages or alter another tool.

  3. 3
    Share it for review

    No Git experience? Send the finished file, its title, and a one-sentence description to the site maintainer.
